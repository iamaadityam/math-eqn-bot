GraphShot

Write f(x) so its curve passes through the target. The curve is shifted vertically so it starts at your soldier.

Syntax help

Operators: + - * / ^ (also **). Functions: abs ln log sqrt sin cos tan exp. Constants: pi e. Variable: x. Trig uses radians. Implicit multiplication works (2x, 3(x+1)). The plane runs from x = -25..25 and y = -15..15. The shot travels to the right and stops when it leaves the field or hits the target.
