how it works

Ranked: hosted 10-player free-for-all

Press Ranked. Your browser joins the match server, which gives the whole queue a 30 second window and then forms rooms of exactly 10 soldiers. Every real human in that window is dealt into the same set of rooms; any empty seat is filled by a server bot whose rating is close to the room average. 60 queued humans become 6 rooms of 10; 3 real humans become one room of 3 + 7 bots. The room is authoritative: one server owns the map, the clock, the locked equations, the beams and the scores.

Rooms are dealt with a rating snake draft: sort everyone by skill, deal in serpentine order, so room averages stay close. It is the same algorithm regardless of queue size.

During the 2 minute code phase everyone writes an equation. Lock in early and the room starts as soon as the last player (or bot) is ready; otherwise the server locks every remaining cannon at 0:00.

Every cannon fires at the same instant. The beams then travel in real time. If a player is killed, their beam is invalid from that instant: any part of their curve that has not arrived yet disappears. A straight line that reaches a sine-wave shooter before their wave reaches you kills the wave too. Score is not zero-sum: kills, survival time and placement all pay. The lobby is a multi-round survival fight: each soldier has 100 health, and each landed hit deals 34 damage. Survivors reposition at least 6 units apart, then a new round starts. The lobby ends when one soldier/bot is left standing. Dead shooters’ beams die with them, and cannons can leave the vertical map and come back.

Bot API (browser)

Every UI action also exists on window.GraphShot. A browser bot can use these methods, or the same stable DOM ids/events. State is broadcast as window events named graphshot:state and graphshot:phase. 
await GraphShot.findMatch()            // join the hosted queue; resolves when the code phase starts
GraphShot.getState()                 // JSON-safe snapshot (phase, connected, match, queue, result)
GraphShot.getMap()                   // soldiers, terrain, your local frame
GraphShot.getConnection()            // server url, status, latency
GraphShot.setName("my-bot")
GraphShot.planShot()                 // { expression, angle, targetSlot } best candidate
GraphShot.submitShot({expression:"0.3*x"})
GraphShot.submitShot({expression:"0.3*x", lock:true})
GraphShot.lockIn()                   // ready now
await GraphShot.waitForPhase("result", 180000)
GraphShot.on("state", fn)            // returns unsubscribe; also "phase" and "error"
GraphShot.getLeaderboard()
GraphShot.getOptions(), setOptions({...})  // practice options
GraphShot.navigate("home")

The DOM is bot-friendly too: #expr, #fire, #s-mode, #s-rel, #s-en, #s-sh, #s-bt, #s-al, #s-ob, #b-new, #b-retry, #nav-play, #qcancel. Inputs fire normal input/change events.

Headless bots: connect to the same server over ws(s)://your-host/ws and speak JSON: hello → queue → wait for a state with phase code → submit (optionally lock:true). Full protocol in BOT_API.md; a complete runnable client is bot.example.js.

Fast local testing: start the server with FAST=1 npm start for a 3s queue and 10s code window. GraphShot.setClock() only works when the server runs with ALLOW_CLOCK=1.

The goal (practice + tutorial)

Your soldier (orange) stands somewhere on the map. Type an equation; when you press Fire! the graph of that equation is drawn starting at your soldier, travelling to the right. Every enemy (blue) the curve touches is killed. Kill all enemies to win.

The map

A normal Cartesian plane: x from −25 to 25 (left → right), y from −15 to 15 (bottom → top). The thick lines are the axes and each small square is 1 unit. Dark blobs are obstacles: if your curve touches one the shot ends there and blows a hole in it. Green soldiers are your allies — your shots kill them too.

How your equation becomes a shot

The curve is always shifted up or down so that it passes through your soldier. That shift is the number shown at the right of the input (e.g. + 6.137). So only the shape of your function matters — not where it would normally cross the axes.

Important: x is the real x‑coordinate on the map, not the distance from you. If you stand at x = −20, then x^2 already has a steep slope at your feet. To get shapes centred on yourself, use (x+20) (if you stand at −20) instead of x. In ranked, x is always measured from your cannon, so 0.3*x is a straight line no matter which side you spawn on.

Special zones (practice)

Shield
red dashed circle		 Around a shielded enemy. The first time your curve touches it, your curve is replaced by its derivative f′(x) — the slope function of what you typed — lifted so it continues from the contact point (no jump). A parabola becomes a line, a sine becomes a cosine, a straight line becomes flat. Works in every mode (in the differential modes the "curve" is the integrated path). Each shield triggers once per shot; the shield disappears when its enemy dies.
Parry bot
purple circle		 A bot that doesn't attack — it defends. Its parry field sits in front of it. Anything that enters is bent back toward you, and your own shot can kill you or your allies. Go around the field (over or under) to reach the bot behind it. Kill the bot and the field vanishes.
Assist field
green dashed circle		 Every ally deploys one (there's no limit on how many allies you can have). If your shot enters it, the shot is caught and steered by the equation you type in that ally's field box: inside the field x = distance travelled in it, y = heading angle in radians (0 = right, + = up), and the value you give is the turn rate (+ turns left/up, − right/down). 0.7 = steady left curl, sin(x*3) = wiggle, 2*(1.57−y) = swing toward straight up. After the shot leaves a field it flies straight along its exit heading, so it can be caught by another field — chain fields to bounce one shot through many enemies. Each field catches a shot once. Empty equation = no steering.
A caught shot is no longer a function of x: it can go backwards or down. A shot redirected by any field can hit you.

What ends a practice shot

  • The curve leaves the map.
  • It touches an obstacle (the obstacle gets a crater).
  • The function becomes undefined — e.g. ln(−1), 1/0 or sqrt of a negative.
Soldiers do not stop a shot — it carries on and can kill several in one go (allies included). If a field sends your shot back into you, you lose that round.

Function types

f(x)The default. The graph of y = f(x), shifted to start at you.
y' = f(x, y)You give the slope of the path at every point; the game integrates it from your position. y' = 0.1 is a line with slope 0.1; y' = -y/10 bends the path back toward the x‑axis. You can use x and y (the height of the path right now).
y'' = f(x, y, y')You give the curvature. You also set a starting angle (degrees, 0 = flat, positive = up). y'' = -0.05 with angle 30° fires a parabolic arc. You can use x, y and y'.
